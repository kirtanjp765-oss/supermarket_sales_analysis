# Supermarket Sales Analysis

This is a data analysis project I built to practice Python, Pandas, and SQL together. The dataset covers supermarket transactions from 7 cities in India across 2023. I generated the data myself using a script since I didn't have access to real data.

I wanted to build something more structured than just a notebook, so I split the code into separate files for loading, cleaning, analysis, visualisation and reporting. I also wrote the same analysis in SQL alongside Pandas to cross check the results.

## Project Structure

```
supermarket_sales_analysis/
├── data/
│   ├── raw/                  generate_data.py + supermarket_sales.csv
│   └── processed/            sales.db (gets created automatically)
├── src/
│   ├── data_loader.py        loads CSV, saves to SQLite
│   ├── clean_data.py         cleaning and feature engineering
│   ├── analysis.py           all analysis functions + SQL queries
│   ├── visualize.py          generates 10 charts
│   ├── export_report.py      exports everything to Excel
│   └── main.py               run this
├── outputs/
│   ├── charts/               PNG charts
│   └── reports/              Excel report
└── requirements.txt
```

## How to run

```bash
pip install -r requirements.txt
cd src
python main.py
```

It will auto-generate the dataset if the CSV is not there, clean the data, run all the analysis, save 10 charts and export an Excel report.

## What I analysed

- Monthly and quarterly revenue trends
- Revenue by city and product line
- Member vs Normal customer comparison
- Payment method breakdown
- Peak shopping hours
- Gender-wise spending by product category
- Customer ratings
- RFM analysis by city (I read about this and tried implementing it)
- Correlation between numeric columns

## Tech used

Python, Pandas, NumPy, Matplotlib, Seaborn, SQLite, openpyxl

## Notes

- Dataset is generated by generate_data.py in data/raw, not downloaded from anywhere
- Pandas and SQL results were cross checked to make sure they match
- All charts are saved as PNG in outputs/charts
